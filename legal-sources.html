Źródła APOMONET

Korzystamy szeroko z faktów, otwartych danych i publicznej dyskusji. Sposób użycia zależy od praw: trwała wiedza, porównanie w czasie analizy albo oznaczony trop badawczy.

Trzy warstwy wykorzystania

Verified Knowledge — fakty z dopuszczonych źródeł, potwierdzone co najmniej dwukrotnie albo przez eksperta. Runtime reference — bieżące porównanie, bez trwałego kopiowania bazy. Community evidence — hipotezy i testy z portali/forów, które nigdy same nie podnoszą pewności ani wyceny.

🟢 OPEN DATA

Nomisma / Wikidata / ANS

Dane strukturalne używane zgodnie z CC-BY, CC0 lub ODbL, z wymaganą atrybucją i provenance.

🟢 OPEN ACCESS

Smithsonian / The Met

Fakty i rekordy Open Access. Obrazy tylko tam, gdzie konkretny obiekt ma właściwe oznaczenie praw.

🟢 ITEM LEVEL

POLONA

Stare katalogi i literatura mogą zasilać badania po sprawdzeniu praw konkretnego obiektu. Status praw zapisujemy przy każdym rekordzie.

🟢 RUNTIME API

Numista

Kandydaci N# są pobierani podczas analizy z widoczną atrybucją „Source: Numista”. Metadane nie są utrwalane jako kopia katalogu, a zdjęcia nie są pobierane.

🟡 OFFICIAL FACTS

NBP

Oficjalne parametry emisji mogą być zapisane własnymi polami z linkiem do źródła. Materiały graficzne NBP pozostają poza importem bez odrębnej podstawy.

🟡 COMMUNITY

Portal Numizmatyczny / Blog Numizmatyczny

Własne, krótkie podsumowania cech i metod diagnostycznych z linkiem. Bez kopiowania akapitów i zdjęć; wynik jest oznaczony jako hipoteza.

🟡 COMMUNITY

TPZN / monetyforum.pl

Wątki specjalistów i kolekcjonerów służą do odkrywania możliwych odmian, falsyfikatów oraz testów. Nie stają się automatycznie prawdą katalogową.

🟡 REFERENCE

PTN Olsztyn / KatalogMonet / Fortress

Źródła porównawcze i pojedyncze fakty własnymi słowami. Bez odtwarzania układu katalogu, masowego importu opisów i obrazów.

🟡 IDS ONLY

IKMK

Identyfikatory Linked Open Data mogą być odsyłaczami. Teksty objęte licencją niekomercyjną nie trafiają do komercyjnej wiedzy APOMONET.

🟡 ITEM REVIEW

Zeno.ru

Wyłącznie konkretny obiekt z jednoznacznie sprawdzoną licencją dopuszczającą dany użytek; brak licencji oznacza brak importu.

🔴 REFERENCE ONLY

Katalog Fischer

Regulamin zabrania kopiowania i rozpowszechniania treści katalogu. APOMONET może wskazać publikację lub numer jako bibliografię, ale nie przejmuje treści ani struktury.

🔴 AUTOMATION

Niemczyk / NumisBids / Coinstrail / Allegro

Bez odpowiedniej zgody brak automatycznego pobierania lub agregowania. Pojedyncze linki i ręczna kontrola są oddzielone od importu.

🟡 SINGLE RECORD

WCN

Kontrolowany importer bezpośrednich kart zapisuje tylko znormalizowane fakty sprzedażowe. Bez opisów, zdjęć, wyszukiwania i paginacji.

🟡 MANUAL FACTS

OneBid / Stary Sklep

Publiczne fakty rynkowe mogą być zapisywane ręcznie z provenance. Szerszy import wymaga osobnej podstawy lub bezpośredniej zgody właściciela materiału.

Fakty rynkowe ≠ Verified Knowledge

Cena sprzedaży zasila statystyki rynku, ale nie potwierdza odmiany. Wiedza numizmatyczna przechodzi do Verified Knowledge dopiero po dwóch niezależnych dopuszczonych źródłach albo potwierdzeniu eksperta.

Twarde granice

Nie obchodzimy logowania, paywalla, CAPTCHA ani blokad technicznych. Nie kopiujemy pełnych opisów, zdjęć ani istotnej części cudzej bazy bez prawa. Każdy automatyczny rekord ma provenance, a trop społecznościowy ma bezpośredni link i własne podsumowanie.
